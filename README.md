# MidtermAce - 期中與證照模擬測驗與刷題系統

> **Ace Your Midterm Exams with Smart Drills & Mistake Workout**
> 
> 基於 **React 19 + TypeScript + Vite + Tailwind CSS** 打造的專業全功能離線題庫模擬測驗與刷題 Web 應用程式。

---

## 🎯 支援目錄下的四種考試題庫 (共收錄 2,153 題)

1. **ICTP 計算機程式語言國際認證 (Python Essentials Level)**
   - **題數**：共 250 題
   - **範圍**：
     - 第一部分：Python 基礎語法與運算 (83題)
     - 第二部分：資料型態、容器與控制結構 (58題)
     - 第三部分：函式、模組與檔案處理 (67題)
     - 第四部分：演算法、物件與進階應用 (42題)
   - **特色**：包含程式碼題目與選項截圖，支援點擊放大檢視 (Lightbox)。

2. **AIL 人工智慧國際認證 (最新人工智慧概論)**
   - **題數**：共 229 題
   - **範圍**：
     - 第一份：人工智慧基礎概論與應用 (單選 72題)
     - 第二份：是非題 (36題) 與 複選題 (23題)
     - 第三份：單選題 (63題) 與 複選題 (35題)
   - **特色**：涵蓋單選題、是非題 (O/X)、多選複選題型。

3. **EEC 企業電子規劃師 - 網路行銷**
   - **題數**：共 250 題
   - **範圍**：
     - 單元一：行銷概念 (40題)
     - 單元二：網路市場與消費者 (60題)
     - 單元三：網路行銷規劃 (90題)
     - 單元四：網路行銷成效分析 (35題)
     - 單元五：顧客模式分析與資料庫行銷 (25題)
   - **特色**：含附圖題型、複選與單選題。

4. **TOEIC 多益核心必考單字與片語**
   - **單字量**：共 1,424 個核心單字片語
   - **範圍**：13 大商務領域（一般商務、製造業、金融預算、企業發展、辦公室、人事、採購、技術、房產、旅遊、外食、娛樂、保健）
   - **特色**：
     - 支援 4 種出題模式：**綜合隨機**、**英選中**、**中選英**、**例句克漏字填空**。
     - **真人美式發音**：點擊喇叭圖示即時語音朗讀 (Web Speech API)。
     - 包含音標、詞性、權威例句、中文翻譯與同反義/衍生詞筆記。

## 🚀 系統核心功能

- **考試模式自由切換**：
  - **模擬考試模式**：計時倒數、答題卡狀態、標記檢查、交卷後統一結算與及格判定。
  - **刷題練習模式**：作答立即揭曉正誤、顯示詳解與考點解析、不限時間。
  - **錯題特訓模式**：專門針對錯題本中的題目集中訓練，答對可一鍵「消滅錯題」。
- **彈性測驗設定**：
  - **自選範圍**：依單元/部分勾選測驗題庫範圍。
  - **自訂題數**：10 題、20 題、30 題、50 題、全部題庫或自訂數字。
  - **亂序防作弊**：題目隨機亂序、選項隨機亂序。
  - **計時設定**：15m / 30m / 50m / 60m / 90m / 不限時。
- **本地持久化儲存 (LocalStorage)**：
  - **錯題特訓本**：自動收錄錯題、記錄累計錯誤次數與上次作答。
  - **對題紀錄**：掌握度進度條、已掌握題數統計。
  - **歷史測驗卷**：保存每次測驗分數、用時、日期與完整作答卷，隨時回顧。
  - **重點題目收藏夾**：隨時點擊書籤星星加入重點題目。
  - **資料備份與還原**：一鍵將做題數據匯出為 JSON 備份檔，或在其他裝置還原。

## 💻 快速啟動方式

本專案已在背景啟動 Vite 開發伺服器：
- 瀏覽器訪問網址：**`http://localhost:3000/`**

若未來需要手動啟動：
```bash
# 安裝依賴
npm install

# 啟動開發伺服器 (開啟 http://localhost:3000/)
npm run dev

# 專案打包
npm run build
```
