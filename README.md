# MidtermAce - 期中與證照模擬測驗、背題與刷題系統

> **Ace Your Midterm Exams with Smart Drills, Study Browser & Mistake Workout**
> 
> 基於 **React 19 + TypeScript + Vite + Tailwind CSS** 打造的專業全功能離線題庫模擬測驗、背題與刷題 Web 應用程式，支援行動版手機介面。

## 🚀 系統核心功能

- **全新「先看題目 / 免測驗背題模式」** 🆕：
  - **無需測驗作答**：直接檢視所有科目完整考題、選項與正解。
  - **雙閱讀模式**：
    - **速讀背題模式 (答案常顯)**：高亮綠色標示正確答案，一眼看懂記憶。
    - **自測回想模式 (點擊查看)**：預設隱藏解答，點擊「查看答案」揭曉，便於自主抽考。
  - **題號直達目錄 (抽屜)**：可點擊右上角題號目錄，直接平滑捲動跳轉至指定題號。
  - **即時過濾與搜尋**：支援輸入關鍵字即時搜尋題目與選項，支援依單元、題型與收藏題目篩選。
- **全新行動版專屬顯示 (Mobile Responsive)** 🆕：
  - **手機專屬底部導覽列 (Mobile Bottom Nav)**：大廳、先看題目、錯題本、收藏夾、數據一觸即達，具未讀標記徽章。
  - **觸控優化**：符合行動裝置點擊半徑（>=44px），支援 iOS/Android PWA 全螢幕獨立體驗。
  - **浮動輔助按鈕**：右下角提供「快速開啟題目目錄」與「一鍵回到頂端」功能。
- **考試模式自由切換**：
  - **模擬考試模式**：計時倒數、答題卡狀態、標記檢查、交卷後統一結算與及格判定。
  - **刷題練習模式**：作答立即揭曉正誤、顯示詳解與考點解析、不限時間。
  - **錯題特訓模式**：專門針對錯題本中的題目集中訓練，答對可一鍵「消滅錯題」。
- **本地持久化儲存 (LocalStorage)**：
  - **錯題特訓本**：自動收錄錯題、記錄累計錯誤次數與上次作答。
  - **對題紀錄**：掌握度進度條、已掌握題數統計。
  - **歷史測驗卷**：保存每次測驗分數、用時、日期與完整作答卷，隨時回顧。
  - **重點題目收藏夾**：隨時點擊書籤星星加入重點題目。
  - **資料備份與還原**：一鍵將做題數據匯出為 JSON 備份檔，或在其他裝置還原。

## 💻 快速啟動方式

本專案已在背景啟動 Vite 開發伺服器：
- 瀏覽器訪問網址：**`http://localhost:3000/`**

若未來需要手動啟動：
```bash
# 安裝依賴
npm install

# 啟動開發伺服器 (開啟 http://localhost:3000/)
npm run dev

# 專案打包
npm run build
```
